# VISIORA V4.2 — Customer style studio
The /my-style route provides an authenticated, mobile-compatible interface to the V4.1 private style intelligence endpoint. Customers choose occasion and maximum budget and see their saved color preferences, selected wardrobe items, missing essentials and transparent non-shopping guidance.

No photo uploads, no purchases, no AI-generated visuals. A Supabase session is required and the API enforces token identity and owner filtering. Follow-up: account navigation entry, richer wardrobe editing, opt-in context and end-to-end browser tests.
