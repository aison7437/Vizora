# VISIORA V4.0 — Premium landing and conversion

Replaces the previous homepage with an editorial, mobile-first layout, accessible style/occasion selection, starter guidance, service discovery, three-step onboarding, privacy messaging, transparent plan previews and account CTAs.

Acceptance after deployment: mobile and desktop visual QA, keyboard navigation, reduced-motion support, screen reader labels, CTA tracking, Lighthouse/Core Web Vitals and conversion funnel instrumentation. No live customer tests have been performed.
